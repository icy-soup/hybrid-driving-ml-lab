# 自动驾驶决策仿真项目：强化学习扩展设计

## 目标

在保留“物理信息增强的数据驱动型自动驾驶算法研究项目”官方背景的前提下，将现有规则策略与行为克隆系统扩展为“规则先验 + 行为克隆 + GPU 强化学习 + 安全屏障”的完整决策实验平台。

最终回答一个可验证的问题：

> 行为克隆提供的专家先验能否帮助强化学习更快学会高效驾驶；在加入安全屏障后，能否减少闭环碰撞，同时保持合理速度和超车效率？

## 项目定位

自动驾驶仍然是项目场景和官方题目，但技术贡献以通用 AI/ML 方法表达：奖励建模、离散控制、经验回放、GPU 训练、模仿学习初始化、安全约束和多策略评测。

不把系统描述为真实车辆控制器，也不把它描述为严格意义上的 PINN。更准确的称呼是“规则约束的行为克隆与强化学习决策系统”。

## 目标训练链路

```text
HighwayEnv
   ├── 场景生成与事件统计
   ├── 可解释奖励分解
   └── reset / step / seed
          ↓
RulePolicy ──→ 示范数据 ──→ Behavior Cloning 初始化
                                  ↓
                       GPU DQN（经验回放 + 目标网络）
                                  ↓
                    SafetyShieldPolicy（部署/评测）
```

## 阶段依赖

强化学习不是当前基线的一部分，而是第二阶段能力。第一阶段必须先冻结以下基线：可复现的 `HighwayEnv`、`RulePolicy`、行为克隆模型、固定场景/随机种子、episode-aware 数据划分和统一评测指标。只有基线结果稳定、能够重复运行并保存 benchmark 后，才开始 DQN 训练；DQN 的所有结果必须使用同一套场景和 seeds 与基线比较。

## 奖励与事件

环境每一步返回总奖励和 `info["reward_components"]`，至少包含：

- `alive`：存活奖励；
- `speed`：接近目标速度的奖励，不奖励无上限加速；
- `progress`：相对道路进展或有效前进；
- `overtake`：车辆从前方安全通过后的事件奖励；
- `ttc_warning`：TTC 低于预警阈值的风险惩罚；
- `lane_change`：变道成本，抑制无意义左右振荡；
- `shield_override`：安全屏障替换神经动作时的惩罚；
- `collision`：碰撞终止惩罚。

奖励权重集中在 `RewardConfig` 中，可以通过配置运行消融实验。初始建议值：存活 `+0.02`，速度 `0–0.05`，安全超车 `+1.0`，TTC 预警 `-0.2`，变道 `-0.01`，屏障接管 `-0.1`，碰撞 `-20`。这些是初始假设，不能直接当作最终结论。

## 强化学习算法

第一版使用 DQN，原因是当前动作空间是 5 个离散动作，DQN 足够解释、容易测试，也能复用现有 11 维观测。

- Q 网络：`11 → 128 → 128 → 5`，ReLU；
- 优化器：Adam；
- 损失：Huber loss；
- 稳定机制：experience replay、target network、gradient clipping；
- 探索：epsilon-greedy，线性衰减并设置最小探索率；
- 设备：优先 `cuda`，否则自动回退 `cpu`；
- 采样：并行多个环境在 CPU 采集，批量训练张量放到 GPU，避免单环境训练浪费 GPU；
- 初始化对照：随机初始化 DQN 与行为克隆初始化 DQN 两组实验。

第一版不引入 prioritized replay、分布式 RL 或复杂 PPO 工程，先保证基线可解释、可复现、可对比。

## 安全策略

训练时记录神经策略的原始动作和实际执行动作。安全屏障在明显紧急风险下覆盖危险动作，并记录 `shield_override`。评测分为：

1. `DQN-raw`：观察纯强化学习策略的闭环行为；
2. `DQN-shielded`：观察规则安全屏障带来的安全收益及效率代价。

这样不会把屏障“藏在”神经网络结果里，便于做诚实的 ablation。

## 实验矩阵

至少比较以下策略：

| 策略 | 作用 |
|---|---|
| RulePolicy | 可解释专家基线 |
| BehaviorCloningPolicy | 监督学习模仿基线 |
| DQN-random-init | 强化学习基线 |
| DQN-BC-init | 行为克隆初始化的强化学习 |
| DQN-BC-init + shield | 混合安全策略 |

每种策略在固定的多随机种子、不同交通密度和风险场景下评测。核心指标：碰撞率、平均存活步数、平均速度、安全超车数、TTC 违规次数、变道次数、平均 episode return、屏障接管率。

## 成功标准

成功不是单纯“训练曲线下降”，而是同时满足：

- 训练可以在 CUDA 上运行，并能在无 GPU 环境自动回退 CPU；
- 随机种子可复现训练和评测；
- DQN 能超过随机策略的存活表现；
- BC 初始化收敛速度和/或早期表现优于随机初始化对照；
- shielded 策略的碰撞率不高于 raw DQN，并报告其速度/超车代价；
- 结果以 JSON、训练曲线和汇总表保存，能够在简历或面试中解释实验设计。

## 非目标

- 第一阶段不重新制作 Pygame 图形界面；
- 不声称现实道路泛化或真实车辆部署；
- 不以一次随机种子结果宣称算法优越；
- 不为了“用上 GPU”而引入不必要的大模型或复杂仿真。
